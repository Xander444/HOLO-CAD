# Gestures and calibration

The [complete controls guide](CONTROLS.md) includes the newer held hand signs for selection, confirmation, cancellation, fit, undo, and redo.

Click the camera button to enable tracking. The preview displays both hands when visible. Hide the preview with its corner button to keep tracking active, or disable the camera to stop the stream.

Use the calibration button to hold both hands open, pinch both thumb–index pairs, then spread your hands and trace the edges of your comfortable reach. Keep your palms visible against an evenly lit background. Begin on the XY plane in Isometric or Top view. A normal webcam measures image positions. The app projects those positions onto a virtual plane or axis.

| Gesture | How to use it |
| --- | --- |
| Select | Hold a single pinch over an object, then release. |
| Draw a line | With **Select** or **Line** active, pinch with both hands. Spread them, then release both pinches close together. The amber prompt accepts an exact length. |
| Extend to a rectangle | With a line selected, hold a pinch near it and pull perpendicular to the line on its sketch plane. Release, then enter an exact height. |
| Extrude | Select a closed sketch. Pinch its extrusion handle and pull in the screen direction of the sketch normal. Release and confirm the depth. Enter a signed number to set the final depth. |
| Orbit | In **Select**, **Move**, **Rotate**, or **Scale**, extend index and middle fingers close together and trace a small arc. Continue moving the pose to orbit. Release to stop. |
| Grab and move | Hold an open hand over a solid, close into a fist, and move. Open the hand to place the solid. Choose an axis in the viewport or with X, Y, or Z for constrained movement. |
| Attach or fuse | When a move finds a connection, the app previews the position and offers **Attach**, **Fuse**, and **Place only**. Attach creates a parent-child relationship. Fuse requires a single valid result. |
| Center | With an active placement, say or type **centered**, or use **Center** at a snap. For two selected solids, select the reference first. A planar face picked on the reference is used when available. Confirm the preview. |
| Scissors | Select a solid. Spread the index and middle fingers into a V and trace the intended cut. Close those two extended fingers to commit. In **Split** mode, the chosen plane controls the cut direction. |
| Delete | Hold a grabbed solid beyond the workspace edge until the red boundary appears. Release to request deletion. Answer **Yes** to delete or **No** to keep the body. |
| Undo and redo | Use the hand-shaped Undo button, Redo, keyboard shortcuts, or the typed or spoken commands. |

A brief loss of tracking freezes the current preview. If the same hands and pose do not return promptly, the app discards the preview. Press Esc at any time to cancel. Pointer input takes priority while you drag. Settings include activation delay, gesture cooldown, confidence, smoothing, pinch threshold, and mirroring.
